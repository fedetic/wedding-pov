<objective>
Build the server-side infrastructure for guest photo uploads: rate limiter singleton, Google Drive upload helper with HEIC→JPEG conversion, and the POST /api/upload/[slug] route handler that ties them together.

Purpose: Guests have no Google account — their photos must be brokered server-side using the organizer's OAuth tokens. This plan implements that entire backend pipeline, keeping tokens strictly server-side.

Output:
- src/lib/rate-limiter.ts — RateLimiterMemory singleton (30 photos/15 min per IP:slug)
- src/lib/drive-upload.ts — Drive upload helper (OAuth2 setup, HEIC→JPEG, resumable upload)
- src/app/api/upload/[slug]/route.ts — POST handler orchestrating all of the above
</objective>

**Step B — Create `src/lib/rate-limiter.ts`:**

Module-level singleton using `RateLimiterMemory`. Key design: 30 points per 15-minute window, 1 point consumed per photo, 10-minute block on exhaustion. This is safe for Railway single-instance deployment.

```typescript
import { RateLimiterMemory } from 'rate-limiter-flexible';

// 30 photos per IP:slug per 15 minutes.
// On Railway single-instance: in-memory is sufficient (no Redis needed for v1).
export const uploadRateLimiter = new RateLimiterMemory({
  points: 30,         // max 30 uploads in the window
  duration: 900,      // 15 minutes in seconds
  blockDuration: 600, // block for 10 minutes after exhaustion
});
```

**Step C — Create `src/lib/drive-upload.ts`:**

This module is server-only (uses googleapis, crypto — never import in Client Components).
The function signature is:

```typescript
export async function uploadFileToDrive(args: {
  file: File;
  nickname: string;
  photoIndex: number;   // 0-based; used to build filename Sarah_001.jpg
  driveFolderId: string;
  organizerId: string;
  encryptedRefreshToken: string;
  accessToken: string | null;
  accessTokenExpiresAt: Date | null;
}): Promise<{ driveFileId: string; fileName: string; mimeType: string; fileSizeBytes: number }>
```

Full implementation:

```typescript
import { google } from 'googleapis';
import { Readable } from 'stream';
import heicConvert from 'heic-convert';
import { decrypt } from '@/lib/crypto';
import { db } from '@/lib/db';
import { googleTokens } from '@/lib/db/schema';
import { eq } from 'drizzle-orm';

export async function uploadFileToDrive({
  file,
  nickname,
  photoIndex,
  driveFolderId,
  organizerId,
  encryptedRefreshToken,
  accessToken,
  accessTokenExpiresAt,
}: {
  file: File;
  nickname: string;
  photoIndex: number;
  driveFolderId: string;
  organizerId: string;
  encryptedRefreshToken: string;
  accessToken: string | null;
  accessTokenExpiresAt: Date | null;
}): Promise<{ driveFileId: string; fileName: string; mimeType: string; fileSizeBytes: number }> {
  // 1. Decrypt refresh token
  const refreshToken = decrypt(encryptedRefreshToken);

  // 2. Build OAuth2 client
  const oauth2Client = new google.auth.OAuth2(
    process.env.GOOGLE_CLIENT_ID!,
    process.env.GOOGLE_CLIENT_SECRET!,
    `${process.env.BETTER_AUTH_URL}/api/drive/callback`,
  );
  oauth2Client.setCredentials({
    refresh_token: refreshToken,
    access_token: accessToken ?? undefined,
    expiry_date: accessTokenExpiresAt ? accessTokenExpiresAt.getTime() : undefined,
  });

  // 3. Persist refreshed tokens back to DB on auto-refresh
  oauth2Client.on('tokens', async (newTokens) => {
    try {
      await db
        .update(googleTokens)
        .set({
          accessToken: newTokens.access_token ?? null,
          accessTokenExpiresAt: newTokens.expiry_date
            ? new Date(newTokens.expiry_date)
            : null,
          updatedAt: new Date(),
        })
        .where(eq(googleTokens.userId, organizerId));
    } catch (err) {
      console.error('[drive-upload] Failed to persist refreshed token:', err);
    }
  });

  // 4. Read file bytes
  const originalArrayBuffer = await file.arrayBuffer();

  // 5. HEIC→JPEG conversion (iOS compatibility)
  const isHeic =
    file.type === 'image/heic' ||
    file.type === 'image/heif' ||
    file.name.toLowerCase().endsWith('.heic') ||
    file.name.toLowerCase().endsWith('.heif');

  let finalBuffer: Buffer;
  let finalMimeType: string;

  if (isHeic) {
    const converted = await heicConvert({
      buffer: Buffer.from(originalArrayBuffer),
      format: 'JPEG',
      quality: 0.85,
    });
    finalBuffer = Buffer.from(converted);
    finalMimeType = 'image/jpeg';
  } else {
    finalBuffer = Buffer.from(originalArrayBuffer);
    finalMimeType = file.type || 'image/jpeg';
  }

  // 6. Build filename: {nickname}_{001}.jpg
  const safeNickname = nickname
    .trim()
    .replace(/[^a-zA-Z0-9_\- ]/g, '')  // strip special chars
    .replace(/\s+/g, '_')
    .slice(0, 40);
  const paddedIndex = String(photoIndex + 1).padStart(3, '0');
  const fileName = `${safeNickname}_${paddedIndex}.jpg`;

  // 7. Upload to Drive
  const drive = google.drive({ version: 'v3', auth: oauth2Client });
  const response = await drive.files.create({
    requestBody: {
      name: fileName,
      parents: [driveFolderId],
    },
    media: {
      mimeType: finalMimeType,
      body: Readable.from(finalBuffer),
    },
    fields: 'id',
  });

  const driveFileId = response.data.id;
  if (!driveFileId) {
    throw new Error('[drive-upload] Drive did not return a file ID');
  }

  return {
    driveFileId,
    fileName,
    mimeType: finalMimeType,
    fileSizeBytes: finalBuffer.byteLength,
  };
}
```

Create `src/app/api/upload/[slug]/route.ts`. This is a Next.js 15 App Router Route Handler. Use `await params` (Next.js 15 pattern — params is a Promise).

The handler must:
1. Parse FormData (fields: `file` as File, `nickname` as string, `photoIndex` as string)
2. Validate inputs (nickname non-empty, file present, photoIndex is a number)
3. Rate limit: extract IP from `x-forwarded-for` header, key = `{ip}:{slug}`, consume 1 point
4. Load event by slug from DB (select id, isActive, driveFolderId, organizerId, photoLimit)
5. Guard: event not found → 404; event.isActive false → 403; event.driveFolderId null → 503
6. Load organizer's Google tokens from googleTokens table (where userId = event.organizerId)
7. Guard: tokens not found → 503 ("Drive not connected")
8. Call `uploadFileToDrive(...)` with all required args
9. Insert uploadRecord into DB with status = 'confirmed', driveFileId, confirmedAt = now
10. Return `{ driveFileId, fileName }` with status 200

Full implementation:

```typescript
import { NextRequest, NextResponse } from 'next/server';
import { db } from '@/lib/db';
import { events, googleTokens, uploadRecords } from '@/lib/db/schema';
import { eq } from 'drizzle-orm';
import { uploadRateLimiter } from '@/lib/rate-limiter';
import { uploadFileToDrive } from '@/lib/drive-upload';
import { randomUUID } from 'crypto';

export async function POST(
  request: NextRequest,
  { params }: { params: Promise<{ slug: string }> },
) {
  const { slug } = await params;

  // 1. Parse FormData
  let formData: FormData;
  try {
    formData = await request.formData();
  } catch {
    return NextResponse.json({ error: 'Invalid form data' }, { status: 400 });
  }

  const file = formData.get('file');
  const nickname = formData.get('nickname');
  const photoIndexRaw = formData.get('photoIndex');

  if (!(file instanceof File) || !file.size) {
    return NextResponse.json({ error: 'Missing file' }, { status: 400 });
  }
  if (typeof nickname !== 'string' || !nickname.trim()) {
    return NextResponse.json({ error: 'Missing nickname' }, { status: 400 });
  }
  const photoIndex = parseInt(String(photoIndexRaw ?? '0'), 10);
  if (isNaN(photoIndex) || photoIndex < 0) {
    return NextResponse.json({ error: 'Invalid photoIndex' }, { status: 400 });
  }

  // 2. Rate limiting — key = IP:slug
  const ip =
    request.headers.get('x-forwarded-for')?.split(',')[0].trim() ??
    request.headers.get('x-real-ip') ??
    'unknown';
  const rateLimitKey = `${ip}:${slug}`;
  try {
    await uploadRateLimiter.consume(rateLimitKey, 1);
  } catch {
    return NextResponse.json(
      { error: 'Too many uploads. Please wait and try again.' },
      { status: 429 },
    );
  }

  // 3. Load event by slug
  const [event] = await db
    .select({
      id: events.id,
      isActive: events.isActive,
      driveFolderId: events.driveFolderId,
      organizerId: events.organizerId,
      photoLimit: events.photoLimit,
    })
    .from(events)
    .where(eq(events.slug, slug))
    .limit(1);

  if (!event) {
    return NextResponse.json({ error: 'Event not found' }, { status: 404 });
  }
  if (!event.isActive) {
    return NextResponse.json({ error: 'Event is not accepting uploads' }, { status: 403 });
  }
  if (!event.driveFolderId) {
    return NextResponse.json({ error: 'Drive folder not configured' }, { status: 503 });
  }

  // 4. Load organizer Google tokens
  const [tokenRow] = await db
    .select({
      encryptedRefreshToken: googleTokens.encryptedRefreshToken,
      accessToken: googleTokens.accessToken,
      accessTokenExpiresAt: googleTokens.accessTokenExpiresAt,
    })
    .from(googleTokens)
    .where(eq(googleTokens.userId, event.organizerId))
    .limit(1);

  if (!tokenRow) {
    return NextResponse.json({ error: 'Drive not connected for this event' }, { status: 503 });
  }

  // 5. Upload to Drive (HEIC→JPEG conversion handled inside uploadFileToDrive)
  let uploadResult: { driveFileId: string; fileName: string; mimeType: string; fileSizeBytes: number };
  try {
    uploadResult = await uploadFileToDrive({
      file,
      nickname: nickname.trim(),
      photoIndex,
      driveFolderId: event.driveFolderId,
      organizerId: event.organizerId,
      encryptedRefreshToken: tokenRow.encryptedRefreshToken,
      accessToken: tokenRow.accessToken,
      accessTokenExpiresAt: tokenRow.accessTokenExpiresAt,
    });
  } catch (err) {
    console.error('[upload] Drive upload failed:', err);
    return NextResponse.json({ error: 'Upload to Drive failed' }, { status: 502 });
  }

  // 6. Insert upload record
  const now = new Date();
  await db.insert(uploadRecords).values({
    id: randomUUID(),
    eventId: event.id,
    organizerId: event.organizerId,
    guestNickname: nickname.trim(),
    fileName: uploadResult.fileName,
    mimeType: uploadResult.mimeType,
    fileSizeBytes: uploadResult.fileSizeBytes,
    driveFileId: uploadResult.driveFileId,
    status: 'confirmed',
    initiatedAt: now,
    confirmedAt: now,
  });

  return NextResponse.json({
    driveFileId: uploadResult.driveFileId,
    fileName: uploadResult.fileName,
  });
}
```

**Do NOT add** `export const config = { api: { bodyParser: false } }` — that is the Pages Router pattern and breaks in App Router.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Guest browser → POST /api/upload/[slug] | Unauthenticated; any internet user can POST to this endpoint |
| POST handler → Google Drive API | Server-to-server; uses organizer OAuth2 tokens (never reaches browser) |
| POST handler → Neon DB | Reads event/token data; writes upload records |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Denial of Service | POST /api/upload/[slug] | mitigate | `uploadRateLimiter.consume(ip:slug, 1)` — 30 photos/15 min, blocks 10 min on exhaustion |
| T-03-02 | Spoofing | ip extraction from headers | accept | `x-forwarded-for` can be spoofed; acceptable for v1 single-instance Railway deployment where rate limiting is advisory not security-critical |
| T-03-03 | Information Disclosure | token handling in drive-upload.ts | mitigate | `decrypt()` called server-side only; no token fields included in JSON responses; `'use client'` cannot import this module |
| T-03-04 | Tampering | malformed/oversized file in FormData | mitigate | File validated (instanceof File, non-zero size); HEIC conversion throws on invalid data → caught, returns 502 |
| T-03-05 | Elevation of Privilege | slug lookup with no ownership check | accept | By design — slug is a public identifier; only non-sensitive event data (name, photoLimit, isActive) is exposed; no organizer PII in response |
| T-03-06 | Repudiation | no audit trail for failed uploads | mitigate | uploadRecords row inserted only on Drive success (status='confirmed'); failed uploads logged to console with error details |
</threat_model>
