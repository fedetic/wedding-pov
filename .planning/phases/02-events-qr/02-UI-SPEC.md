# Phase 2 — UI Design Contract: Events + QR

> Visual and interaction contract for Phase 2 (Events + QR). Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none — hand-rolled Tailwind v4 utility classes (established in Phase 1) |
| Preset | not applicable |
| Component library | none — no Radix, no shadcn |
| Icon library | none — use text labels and Unicode symbols (✓, ×, ↓) |
| Font | Geist Sans via `next/font/google` — already loaded in `layout.tsx` |

**Rationale:** shadcn is not needed for an internal organizer tool with 1–2 users. Phase 1 established the hand-rolled pattern; this phase extends it consistently.

---

## Spacing Scale

Declared values (multiples of 4 only):

| Token | px value | Tailwind class | Usage |
|-------|----------|---------------|-------|
| xs | 4px | `gap-1`, `p-1` | Icon gaps, inline badge padding |
| sm | 8px | `gap-2`, `p-2` | Compact element spacing, error banner padding |
| md | 16px | `gap-4`, `p-4` | Default form element spacing |
| lg | 24px | `gap-6`, `p-6` | Card/section internal padding |
| xl | 32px | `gap-8`, `p-8` | Page-level padding |
| 2xl | 48px | `mb-12` | Major section breaks |
| 3xl | 64px | not used in this phase | Reserved |

Exceptions:
- Table row padding: `px-4 py-3` (horizontal 16px, vertical 12px) — maintains text alignment without excessive row height
- Toggle button touch target: minimum 44px height via `min-h-[44px]` for accessibility
- Modal backdrop: full viewport — no spacing token applies

### 3. Event list table (within Dashboard Events section)

**Rendered inside** the Events section card (`border rounded-lg p-6`).

**Columns:** Name | Photo limit | Status | Actions

```
┌──────────────────┬──────┬──────────┬─────────────────────────┐
│ Name             │ Limit│ Status   │ Actions                 │
├──────────────────┼──────┼──────────┼─────────────────────────┤
│ Our Wedding      │  30  │ ● Active │ [QR code] [Deactivate]  │
│ Reception        │  20  │ ○ Inactive│ [QR code] [Activate]   │
└──────────────────┴──────┴──────────┴─────────────────────────┘
```

**Table implementation:**
- `<table className="w-full text-sm">` — full width, text-sm
- `<thead>` row: `bg-gray-50` — `text-left text-xs font-medium text-gray-500 uppercase tracking-wide px-4 py-2`
- `<tbody>` rows: `border-t border-gray-100` between rows, `px-4 py-3`
- Column widths: Name auto, Limit 80px, Status 100px, Actions auto

**Status badge:**
- Active: `<span className="inline-flex items-center px-2 py-0.5 rounded-full text-xs font-medium bg-green-100 text-green-800">Active</span>`
- Inactive: `<span className="inline-flex items-center px-2 py-0.5 rounded-full text-xs font-medium bg-gray-100 text-gray-600">Inactive</span>`

**Action buttons (in each row):**
- "QR code" — `<button className="text-sm underline font-medium mr-3">QR code</button>` — triggers QR modal
- Toggle active/inactive — `<button className="text-sm underline font-medium">` — text changes based on current state:
  - When active: "Deactivate"
  - When inactive: "Activate"
  - Loading state: "Saving…" with `opacity-50 cursor-not-allowed`

**Toggle behavior:** Optimistic update — immediately flip the status badge and button label, send PATCH to `/api/events/[id]/toggle`, revert on error with error banner at top of section.

### 4. QR code modal

**Trigger:** "QR code" button in event list row  
**Pattern:** Overlay modal — rendered via React portal or inline conditional render at page level

```
Backdrop: fixed inset-0 bg-black/50 z-50 flex items-center justify-center

┌──────────────────────────────────────────┐
│                           [×]            │  card: bg-white rounded-lg p-6 w-full max-w-sm mx-4
│  QR code                                 │
│  {Event name}  ← text-sm text-gray-500   │
│                                          │
│  ┌──────────────────────────────────┐    │
│  │                                  │    │  QR image: 256×256px centered
│  │        [QR code image]           │    │
│  │                                  │    │
│  └──────────────────────────────────┘    │
│                                          │
│  [Download QR code]   ← primary button   │
│                                          │
└──────────────────────────────────────────┘
```

**Close behavior:**
- × button: `absolute top-4 right-4` — `text-gray-400 hover:text-gray-600 text-xl`
- Click backdrop: closes modal
- `Escape` key: closes modal

**QR code specs:**
- Size: 256×256px rendered in `<img>` tag
- Content: full URL `https://{host}/e/{slug}` — must be absolute URL with protocol for QR scanners
- Error correction: Level M (15%) — standard for print
- White quiet zone: 16px on all sides (included in the 256px)
- QR library: `qrcode` npm package (generates data URL client-side)

**Download button:**
- Label: "Download QR code"
- Behavior: programmatically creates an `<a download="qr-{event-slug}.png">` with the canvas/image data URL and clicks it
- File name format: `qr-{event-slug}.png` — e.g. `qr-our-wedding.png`
- Loading state: "Generating…" with `opacity-50` while QR renders
