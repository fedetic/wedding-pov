## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-03-01 | Information Disclosure | Session token in native Preferences storage | accept | @capacitor/preferences uses iOS Keychain / Android EncryptedSharedPreferences for persistent storage; this is more secure than a WebView cookie. Tokens are scoped to the app's bundle ID. |
| T-05-03-02 | Spoofing | Capacitor.isNativePlatform() spoofing | accept | isNativePlatform() reads a flag set by the Capacitor native bridge at startup; it cannot be spoofed from web context without native-level access. |
| T-05-03-SC | Tampering | better-auth-capacitor npm package | mitigate | Package is from productdevbook (referenced in PITFALLS.md and CONTEXT.md as the correct solution). Before install, verify the package on npmjs.com: npm info better-auth-capacitor. Check for unexpected maintainers or version anomalies. If the package does not exist on npm, fall back to the token-in-localStorage pattern described in ARCHITECTURE.md and flag for human review. |
</threat_model>
