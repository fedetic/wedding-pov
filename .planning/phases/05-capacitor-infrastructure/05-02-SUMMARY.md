## Decisions Made

1. **server.url uses process.env fallback:** The `.env.local` has `NEXT_PUBLIC_APP_URL=http://localhost:3000` (dev URL). Since this is the dev env, not a Railway production URL, `capacitor.config.ts` uses `process.env.NEXT_PUBLIC_APP_URL ?? "https://wedding-pov-production.up.railway.app"` as the plan template specified. The Railway URL is the correct production target.

2. **ios/ and android/ committed to git:** Capacitor convention is to commit native project directories. They contain no secrets. Signing keys are not stored in the project.

3. **WKAppBoundDomains scoped narrowly:** Only `wedding-pov-production.up.railway.app` declared — not a wildcard. ITP relaxation is scoped only to our server domain.

4. **NSAllowsArbitraryLoads NOT added:** Railway is HTTPS; ATS (App Transport Security) remains enabled as required.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] Node 22 required for @capacitor/cli@8**

- **Found during:** Task 2 (`npx cap add ios` failed)
- **Issue:** `@capacitor/cli@8.3.4` requires `node >=22.0.0`; system had Node 20.19.6. The `cap add` commands exited with `[fatal] The Capacitor CLI requires NodeJS >=22.0.0`.
- **Fix:** Installed `node@22` via `brew install node@22`, then ran `cap add ios`, `cap add android`, and `cap sync` with `PATH="/opt/homebrew/opt/node@22/bin:$PATH"`. The project's server-side (Railway, Next.js) continues to use Node 20 — this is only for local CLI tooling.
- **Files modified:** None (brew install is local tooling, not a project file)
- **Note:** This is a local developer machine requirement. Other developers working on this project will need `node >=22` to run `npx cap` commands. Consider adding this to a `.nvmrc` or project README.

**2. [Rule 3 - Blocking] Missing android/app/src/main/assets/ directory**

- **Found during:** Task 2 (`npx cap sync` failed on first run)
- **Issue:** `cap sync` failed with `ENOENT: no such file or directory, open '.../android/app/src/main/assets/capacitor.config.json'` — the `assets/` directory was not generated by `cap add android`.
- **Fix:** Created the directory manually with `mkdir -p android/app/src/main/assets`, then re-ran `cap sync` which completed successfully.
- **Files modified:** `android/app/src/main/assets/` directory created (and later populated by cap sync with `capacitor.config.json` and `capacitor.plugins.json`)
