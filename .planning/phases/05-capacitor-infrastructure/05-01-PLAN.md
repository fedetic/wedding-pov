    In next.config.ts, update the async headers() function to:

    1. REMOVE the line `{ key: "X-Frame-Options", value: "DENY" }` entirely. Per D-06: this header blocks the Android Capacitor WebView from loading Railway-served pages.

    2. ADD a second headers entry scoped to `/api/(.*)` paths only, with CORS headers for the two Capacitor origins. The CORS headers must support credentials. Because Access-Control-Allow-Origin cannot be a wildcard when credentials are required, implement dynamic origin reflection: check the incoming origin and only reflect it if it is in the Capacitor allowlist.

    The updated next.config.ts must look like this exactly:

    ```typescript
    import type { NextConfig } from "next";

    const CAPACITOR_ORIGINS = ["capacitor://localhost", "http://localhost"];

    const nextConfig: NextConfig = {
      async headers() {
        return [
          {
            source: "/(.*)",
            headers: [
              { key: "X-Content-Type-Options", value: "nosniff" },
              // X-Frame-Options: DENY removed — blocks Capacitor WebView on Android
              { key: "Referrer-Policy", value: "strict-origin-when-cross-origin" },
              { key: "Permissions-Policy", value: "camera=(), microphone=(), geolocation=()" },
            ],
          },
        ];
      },
    };

    export default nextConfig;
    ```

    NOTE: next.config.ts `headers()` only supports static header values — it cannot do dynamic origin reflection per-request. Dynamic CORS (reflecting the request Origin) must be done in middleware or individual route handlers, not in next.config.ts static headers config.

    Therefore the approach for CORS headers is: add them to the Better Auth trusted origins (Task 1 covers this), and add a note in a comment about per-request CORS. The `X-Frame-Options: DENY` removal is the critical change from next.config.ts; actual CORS allow-origin headers for Capacitor are enforced server-side by Better Auth via trustedOrigins (which we already set in Task 1).

    The final next.config.ts is:
    - Remove `{ key: "X-Frame-Options", value: "DENY" }` from the global headers array
    - Keep all other three headers unchanged
    - Do not add output: 'export' (server.url approach, per D-01)
    - Do not add any CAPACITOR_BUILD conditional logic
    - Keep the file under 25 lines
  </action>
