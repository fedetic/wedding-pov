Default flags (do not override):
- `--iosProject`: defaults to `ios/App` (correct for this project)
- `--androidProject`: defaults to `android` (correct)
- `--assetPath`: defaults to `assets/` then `resources/` (we use `assets/`)
- `--logoSplashScale`: default 0.2 (logo is 20% of splash width — acceptable)

Output paths the tool will write:
- iOS icon set: `ios/App/App/Assets.xcassets/AppIcon.appiconset/` (overwrites Contents.json and adds AppIcon-{size}@{x}.png files)
- iOS splash: `ios/App/App/Assets.xcassets/Splash.imageset/` (overwrites Contents.json + splash-2732x2732.png variants)
- Android adaptive icon mipmaps: `android/app/src/main/res/mipmap-{m,h,xh,xxh,xxxh}dpi/ic_launcher{,_round,_foreground}.png`
- Android adaptive icon XML: `android/app/src/main/res/mipmap-anydpi-v26/ic_launcher.xml` and `ic_launcher_round.xml`
- Android splash: `android/app/src/main/res/drawable*/splash.png`
